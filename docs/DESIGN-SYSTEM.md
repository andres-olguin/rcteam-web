# RC Team — Sistema visual editorial 2026

## Dirección de arte
Referencia aprobada como línea estética, no como composición pixel a pixel: contrastes en azul eléctrico, cian, azul noche, blanco, tipografía editorial de gran tamaño, fotocomposición urbana y movimiento medido.

## Tokens principales
- Navy: #06172e
- Azul: #1267ee
- Cian: #21bafa
- Blanco: #ffffff
- Papel: #f5f8fe
- Tipografía títulos: Manrope, fallback DM Sans.
- Tipografía interfaz: DM Sans, fallback Arial.

Las variables están en styles.css. No convertir el sitio en un framework sin una necesidad técnica confirmada.

## Secciones
Hero; estrategia y servicios; metodología; mosaico de medios con filtros; eficiencia; territorios; filosofía; Team; contacto.

## Responsive y accesibilidad
Desktop ancho máximo de 1330 px. Tablet 850 px. Móvil 570 px. Probar además a 320 px.
Utilizar HTML semántico, teclado, foco visible, aria-expanded y reduced-motion. Confirmar visualmente el contraste.

## Identidad
Dos logos suministrados, optimizados como WebP. Fotografías de Unsplash solamente como demostración, nunca atribuirlas a campañas ejecutadas por RC Team. Ver docs/ASSETS.md.

## Pendiente de validar
Fotografías, nombres y cargos reales de 4–5 integrantes. Aprobación de textos, media y branding del cliente. Mecanismo definitivo del formulario.
